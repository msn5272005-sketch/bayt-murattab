# بيت مرتب

موقع عربي متجاوب لتنظيم المنزل والمطبخ، منشور على GitHub Pages.

https://msn5272005-sketch.github.io/bayt-murattab/

## المحتوى
ستة منتجات محددة بمعرفات ASIN، مع مصادر وحدود تحقق منشورة في صفحة كل منتج وفي PRODUCT-SOURCES.md. البحث والتصفية والترتيب وصفحات التفاصيل والإفصاح والخصوصية تعمل داخل المتصفح. لا توجد أسعار أو تقييمات أو ادعاءات توفر أو تجربة عملية. الرسومات رموز توضيحية وليست صور المنتجات.

روابط Amazon.sa تستخدم معرف الشريك الحقيقي baytmurattab-21 الذي قدمه صاحب الموقع. لم يتم التحقق من إسناد العمولات داخل لوحة حساب أمازون؛ تحقق منه من التقارير وأدوات البرنامج. لا يحتاج تحديث الموقع كلمات مرور أمازون.

## النشر
الملفات index.html وstyle.css وproducts.js وapp.js في جذر المستودع. Pages مضبوط على main و/(root)، وإيداع التغييرات يعيد النشر تلقائيًا. لا حاجة لبناء أو تثبيت حزم.

## التحرير
أضف أو عدل المنتجات في products.js. احتفظ بالمصدر والتحفظات، واستخدم ASIN الحقيقي فقط. لا تضف سعرًا أو تقييمًا يدويًا. راجع المواصفات المتعارضة مع البائع، واحذف المنتجات أو الروابط التي لم تعد صالحة.

## الفحص
يتضمن tests/smoke.cjs محاكاة DOM محدودة لـ66 تحققًا. لتشغيله من جذر مستودع GitHub:

```sh
node --check app.js
node --check products.js
node tests/smoke.cjs
```

انظر TESTING.md لحدود الفحص. يستخدم الخط Google Fonts مع خط محلي بديل؛ لا توجد أدوات تحليلات أو حسابات مستخدمين أو دفع في كود الموقع.
