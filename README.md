# بيت مرتب

https://msn5272005-sketch.github.io/bayt-murattab/

موقع عربي RTL للتسويق بالعمولة: ست صفحات منتجات مستقلة، بحث وتصفية وترتيب، دليل اختيار، إفصاح وخصوصية. لا يدير دفعًا أو طلبات. لا توجد أسعار أو تقييمات أو ادعاءات تجربة فعلية. الصور رموز توضيحية مع تسمية واضحة؛ لا توجد صور منتجات ذات ترخيص موثق بعد.

## التعديل والبناء

عدّل products.js أو app.js أو style.css، والقالب العام scripts/template.html. ثم نفذ:

```sh
node --check app.js
node --check products.js
node scripts/build.cjs
node tests/smoke.cjs
node tests/static.cjs
```

يولّد البناء صفحات HTML ومعلومات canonical وOpen Graph وJSON-LD وخريطة sitemap.xml. صفحات المحتوى والمنتجات قابلة للقراءة دون JavaScript؛ البحث والتصفية يتطلبانه. تُحفظ المخرجات في المستودع، وينشر GitHub Pages من main وجذر المستودع؛ يجب إعادة البناء قبل الرفع. الروابط القديمة ذات #/ مدعومة.

معرف العمولة baytmurattab-21؛ زر منظم أدوات المائدة يستخدم رابط SiteStripe المعتمد. لم يجرِ التحقق من إسناد العمولات داخل الحساب. انظر PRODUCT-SOURCES.md وTESTING.md لمصادر المعلومات والتحفظات وحدود الفحص.

لا تحليلات أو ملفات تتبع في كود الموقع ولا تحميل خطوط خارجية. الشراء لدى Amazon.sa، التي تطبق سياساتها عند الانتقال إليها.
